Hetren Product Research Architecture and Market Validation Specification

## Current execution authority

Hetren Cross-Domain Intelligence MVP Plan v2.0, dated 2026-09-16.

Where sequencing differs, MVP v2.0 controls the current build.

## Initial MVP scope

The initial cross-domain qualification program contains:

1. a tool-using agent environment;
2. a structured-data ML environment;
3. a vision environment.

Both Behavioral and authorized Internal Engines are first-class MVP
capabilities.

A Hetren-developed native neural prototype must be implemented, trained,
ablated, and evaluated as a research deliverable.

## Legacy implementation

The active MVP architecture does not depend on the previous ASR-first
implementation.

The pre-reset repository is preserved at:

- branch: `legacy/pre-mvp-v2-20260916`

Historical evidence retains its original scope and identity.

Legacy code may be reintroduced only after an explicit decision that it
satisfies a current MVP contract. Reintroduction is not automatic reuse.

## Evidence rule

Specifications describe direction and requirements.

Repository implementation, executed tests, qualification records, and
evaluation evidence establish implementation status.

No capability is considered complete because it appears in a planning
document.
