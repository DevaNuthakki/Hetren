## Protected scientific question

The protected P09.4 question is:

> Under a richer controlled multi-step incident environment, a frozen replay
> cost catalogue, and a shared budget of 13 units, does cost-aware active
> diagnosis C3 improve correct-specific diagnosis over maximum-information-gain
> C2 while preserving false-specific safety?

This is a diagnosis-policy question.

It is not yet a repair-effectiveness, production, latency, monetary-cost, or
real-world generalization question.

## Exact paired statistical test

The confirmatory statistical test is the two-sided exact McNemar test on the
discordant correct-specific outcomes.

Let:

- `w = c3_only_correct`;
- `l = c2_only_correct`;
- `n = w + l`;
- `m = min(w, l)`.

If `n = 0`, the exact p-value is `1.0`.

Otherwise:

`p = min(1, 2 * sum(comb(n, k), k=0..m) / 2**n)`

No continuity correction is used.

No asymptotic approximation is substituted.

The test may be implemented with the Python standard library.

No additional statistical package is required.

---

## Confirmatory alpha

The confirmatory paired-test threshold is:

**two-sided exact p <= 0.05**

There is exactly one confirmatory statistical hypothesis test.

Secondary comparisons are descriptive and do not receive confirmatory claim
authority.

Therefore no multiple-testing adjustment is applied to the single
confirmatory P09.4 H1 test.

## H1 support decision

P09.4 H1 is `SUPPORTED` only if the protected study is scientifically valid
and all of the following are true:

1. C3 minus C2 correct-specific rate is at least `+0.10`;
2. `c3_only_correct > c2_only_correct`;
3. the two-sided exact McNemar p-value is `<= 0.05`;
4. C3 correct-specific count is greater than or equal to C2 in at least four

5. C3 false-specific count is exactly zero across all 144 protected cases.

All five criteria are conjunctive.

Failure of any one criterion prevents `SUPPORTED`.
