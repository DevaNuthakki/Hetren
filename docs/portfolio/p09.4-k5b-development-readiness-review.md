Population-plan readiness
-------------------------

cases.

36 public slots per template.

Public slot identity and public nuisance configuration are constructed before
hidden assignment and are independent of hidden generation-seed assignment.

Materialization readiness
-------------------------

public-slot metadata.

V2 provides 36 deterministic, real, fault-neutral input-order variants while
preserving canonical target-incident order and target service scope.

V3 provides 36 public benign policy-context variants. Context remains only at
checkpoint boundaries where the replay contract permits context, and the
benign value survives the fresh-context P4 replay path.

V4 provides 36 public non-target identifier variants while preserving target

All 864 possible combinations of public template, public slot, and possible

Across those combinations, 4,320 real checkpoint replays preserved the frozen
registered probe semantics and calibrated physical replay costs.

Every materialized baseline remained failing.

Target service scope remained unchanged.

Treatment-visible run identity is exactly the public case ID and does not
encode the hidden stratum or expected hypothesis.

The materializer does not create randomness, persist protected artifacts,
execute C0-C3 scientific arms, or execute protected evaluation.

Evaluator readiness
-------------------

The separated evaluator consumes already-frozen treatment records and
evaluator-side hidden assignments.

It does not execute treatment or materialize baselines.

It preserves the frozen 120-case in-RFS denominator and treats valid
unfavorable outcomes such as INCONCLUSIVE and BUDGET_EXHAUSTED as denominator
outcomes rather than removing them.

It implements the preregistered C3-v-C2 paired table, exact two-sided McNemar
calculation, practical-effect requirement of at least +0.10, four-of-five
in-RFS fault-stratum breadth requirement, and zero-C3-false-specific safety
requirement.

SUPPORTED, NOT_SUPPORTED, and BLOCKED remain distinct conclusions.

Missing or structurally invalid protected treatment evidence blocks evaluation
rather than shrinking the denominator.

Separation review
-----------------

Generation, materialization, treatment execution, and evaluation remain
separate responsibilities.

The generation-plan layer may know evaluator-side hidden assignment while
constructing the development plan, but public slot construction remains
seed-independent.

The materialization boundary consumes a matched public slot and evaluator-side
hidden assignment only to instantiate the latent controlled environment. The
returned treatment-visible replay baseline does not use hidden truth as a
treatment-policy input.

The scientific-arm engine remains the treatment-policy layer.

The evaluator remains downstream of frozen treatment evidence.

This separation does not by itself prove organizational independence, external
infrastructure independence, provider independence, or real-world validity.
