# Hetren

Shared intelligence for improving AI systems.

Hetren is being rebuilt around a common intelligence and evidence Core that
can investigate, improve, implement, verify, and remember changes across
different AI system families.

## Current status

MVP v2 foundation.

The active MVP qualification program targets:

- tool-using agent systems
- structured-data ML systems
- vision systems
- Behavioral and Internal Engines
- shared method construction
- independent verification
- native Hetren neural-intelligence research

The repository intentionally does not preserve the previous ASR-first
implementation as the active architecture.

## Repository

- `apps/` — deployable product applications
- `packages/` — shared product and research-independent modules
- `environments/` — qualified MVP system families
- `research/` — native intelligence, baselines, training, and evaluation
- `tests/` — cross-repository verification suites
- `infra/` — local and container infrastructure
- `docs/` — architecture, decisions, MVP records, and research
- `scripts/` — repository-level development and release tooling

See `docs/architecture/repository-layout.md` for boundary definitions.

## Project authority

The long-term product direction is defined by Hetren Product Research
Architecture and Market Validation Specification v1.4.

The current MVP execution authority is Hetren Cross-Domain Intelligence
MVP Plan v2.0.

Implementation status must be established by repository evidence and must
not be inferred from the product specifications.
